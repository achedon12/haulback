# Security Policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please do **not** open a public issue for a security problem.

Report it privately through [GitHub's private vulnerability reporting](https://github.com/achedon12/haulback/security/advisories/new). You will get an answer as soon as possible, and credit in the release notes if you wish.

Haulback is a client-side mod: it does not open network ports and only talks to the Minecraft server you join. Relevant reports include, for example, a crafted schematic file that crashes or misbehaves the client, or anything that could make the bot act outside what the player configured.
